# Solar System MCP Server

provides access to Solar System astronomical data from the API at https://api.le-systeme-solaire.net/en/

## Claude Plugin

This directory is a Claude plugin. It contains:

- `.claude-plugin/plugin.json` — plugin manifest
- `.mcp.json` — MCP server configuration
- `skills/` — 1 bundled skill(s)

## Installation

Copy this entire directory into your project to use as a Claude plugin.
